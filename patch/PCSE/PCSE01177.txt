# Iconoclasts [US]
#
# The game (Chowdren engine) keeps a 1280x720 logical window and maps it to
# the display by halving every coordinate, into a 640x368 framebuffer
# (pitch 1024) that the Vita then scales. @FB moves the display buffers,
# colour surface, render target, surface clip and the window-to-device
# mapping (region clip + viewport, and the screen-capture helper) to the
# configured framebuffer size, keeping the 16:9 area centred.
#
# Window -> device scale is fb_w / 1280, done in the code as (w << k) + w
# followed by >> m; the k / m pairs for the four framebuffer widths are
# looked up from small tables indexed by ((fb_w / 80 - 6) % 5):
#   960x544: x3 >> 2   720x408: x9 >> 4   640x368: x2 >> 2   480x272: x3 >> 3
# Offsets are for module NID 0x2AE04E1D.
