# Rogue Legacy [US]
#
# Cellar Door Games' C++ XNA-style port (module RogueCastle, SilverWare
# allocator). The scene is drawn into a 960x524 off-screen render target and
# composited into a 960x544 display buffer through an XNA-like SpriteBatch
# whose projection comes from the engine's logical 960x544 viewport, while the
# GXM viewport is always the full render target (sceGxmSetViewport /
# sceGxmSetRegionClip are never used). @FB therefore only has to move the
# physical display objects; the logical size stays 960x544 and the picture is
# scaled by the hardware. The display buffers keep their native 2 MiB
# allocation (always >= the patched size), so the row clear / memset sizes
# stay untouched.
#
# Frame pacing: the display queue callback (sceGxmInitialize, maxPending 2)
# calls sceDisplaySetFrameBuf(sync=1) then one sceDisplayWaitVblankStart.
# @FPS unrolls extra sceDisplayWaitVblankStart calls into the callback's
# stack-canary check (a 24-byte fixed frame, the check is redundant): 1, 2 or
# 3 waits for 60 / 30 / 20 FPS. The game timer is real time
# (sceKernelGetProcessTime), so the game speed does not change.
# Offsets are for module NID 0xF5B8765B.
