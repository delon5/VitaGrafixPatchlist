# The Legend of Heroes: Zero no Kiseki Evolution [JP]
#
# Chara-Ani 2012 port of the Falcom PSP game on the "Hachi" engine (module "nana"),
# the 2012 build of the engine that also runs Ao no Kiseki Evolution (PCSG00246).
# The scene is drawn straight into the 960x544 display buffer.
#
# @MSAA is the only complete option in this file. Every fragment program is created
# at one call site (r3 = multisampleMode), so all render targets must and do get the
# same mode: the five sceGxmCreateRenderTarget sites, the five sceGxmColorSurfaceInit
# scale modes and all four sceGxmDepthStencilSurfaceInit strides plus their memory
# blocks are scaled together (2x doubles the sample rows, 4x doubles both axes).
#
# @FPS is NOT in this file. The vcount + clock-retiming construction works and is
# verified (see PCSG00042.report.md), but the minigame mode (fn 0x15252E, ids 0/3/8/9/
# 10/11/42/43/50/51/52) runs its whole logic once per rendered frame with integer frame
# counters (e.g. fn 0x172E46 timeline [+0x444] vs 50/60/61/81/93/103/144), so it would
# run at double speed at 60 FPS. Per the brief a partial unlock stays in the report.
# @FB  not achieved: 960/544 are hard-coded through the whole display path and the 2D
#       layer; there is no final blit to rescale (see the report).
# @IB  not applicable: the scene is drawn into the display buffer; the engine's dormant
#       low-resolution path (ctx+0x3594, fns 0x11774C/0x117764) has no caller.
